### 🛡️ Filosofía & Arquitectura

- ☁️ **Soberanía Digital:** Servidor personal como fuente de verdad (`sv`); estaciones de trabajo y laptops efímeras.
- 🐧 **Entorno Artesanal:** CachyOS con Wayland/Hyprland y terminales optimizadas para latencia cero y estética cuidada.
- 🔐 **Seguridad Zero-Trust:** Dotfiles y secretos versionados bajo cifrado `age` + `chezmoi`.
- 🧠 **Memoria Aumentada:** Flujos de trabajo e inteligencia personal potenciados mediante `Exocortex` (local-first MCP).
